# website-wifi-uas

Project ini merupakan hasil **Ujian Akhir Semester (UAS) Web 2** berupa website layanan internet/WiFi yang menyediakan informasi paket internet, promo, testimoni pelanggan, FAQ, serta fitur pendaftaran pelanggan baru secara online.

---

## 🎯 Tujuan Project
- Menyediakan media informasi layanan internet/WiFi
- Memudahkan calon pelanggan melakukan pendaftaran
- Menerapkan konsep CRUD dan basis data relasional
- Mengimplementasikan hasil pembelajaran Web 2

---

## ⚙️ Fitur Aplikasi
- Manajemen Paket Internet
- Manajemen Promo
- Manajemen Testimoni
- Manajemen FAQ
- Sistem Login Admin
- Pendaftaran Pelanggan Baru

---

## 🛠️ Teknologi yang Digunakan
